# profiles/ — 把「引擎」和「口味」分开

## 为什么需要这个目录

[`SKILL.md`](../SKILL.md) 和 [`docs/workflow.md`](../docs/workflow.md) 描述的是**客观规律**——曝光 p50 该落在哪、曲线怎么分离冷暖、哪些坑会毁掉工作。这些对所有人成立。

但**「好看」是主观的**。

同一个「黄昏暖调」，有人要的是克制、贴近现场；有人要的是浓郁、情绪化。如果这两个人的 AI 共用同一份指令，**总有一个人的照片会被修成另一个人的口味**——而且他可能说不出哪里不对，只觉得「不像我拍的」。

所以：**引擎共用，口味各写各的。**

---

## 怎么用

在 `profiles/` 下建一个以你名字命名的文件，例如 `profiles/alex.md`。

**每次让 AI 调图时，把它和 `SKILL.md` 一起给 AI。** 它会按你的偏好约束风格决策。

---

## 模板

复制下面这段，删掉不适用的，填上你自己的：

```markdown
# <你的名字> 的风格档案

## 我拍的什么
<题材：街头 / 人像 / 风光 / 纪实…>
<器材、常用焦段>

## 我要的感觉
<三言两语描述你追求的氛围。越具体越好。>

## 我喜欢的
- <例如：保留现场光的真实感>
- <例如：暗部留细节，不要压死>
- <例如：肤色自然，不要统一成一种橙>

## 我讨厌的（重要，请严格遵守）
- <例如：滤镜感、过度风格化>
- <例如：无谓的压暗>
- <例如：人物被 AI 磨皮磨得像塑料>

## 沟通方式
- <例如：先告诉我你打算往哪个方向调，我确认了再动手>
- <例如：给我数字（直方图）和对比图，不要只说「调好了」>
- <例如：调错了直接说，别绕>

## 常用风格锚点
| 场景 | 方向 |
|---|---|
| <阴天街头> | <冷青、低饱和、保持通透> |
| <黄昏> | <暖调但不腻，高光别过> |
```

## 示例

[`example-natural-street.md`](example-natural-street.md) 是一份填好的实例，来自一位偏好**克制纪实**的街头摄影师。可以直接参考它的具体程度——**写得越具体，AI 越不会自作主张。**

---

## 注意

- 这份档案是**给 AI 看的约束**，不是给你自己看的宣言。所以**「我讨厌什么」比「我喜欢什么」更有价值**——否定条件能直接挡掉错误方向。
- 口味会变。改了偏好就更新它，**这是这个文件存在的意义**。
- 如果你发现某条偏好其实对所有照片都成立（不是个人口味，而是客观更好的做法），那它应该被提升到 `SKILL.md` 或 `docs/` 里，而不是留在个人档案。

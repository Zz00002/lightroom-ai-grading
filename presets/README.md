# presets/ — 真正能共享的修图成果

## 为什么 `.xmp` 是本仓库的精髓

前面在 [README](../README.md#关于协作) 里说过一个很多人不知道的事实：

> **Lightroom Classic 的目录（`.lrcat`）无法合并。**
> 两个人不可能共用一个目录，只能各修各的。

那「共享修图成果」到底靠什么？

**靠 `.xmp`。**

Lightroom 的预设就是**纯文本 XML**，体积几 KB，**能 diff、能 review、能回滚、能合并**——它具备版本控制需要的一切属性。而 `.lrcat` 一条都不具备。

所以这个目录是两个人协作的**唯一实质载体**：你调出一个满意的风格，存成 `.xmp` 提交；你朋友 `git pull`，导入 Lightroom，就得到了完全一样的效果。

---

## 怎么从 Lightroom 导出预设

### 方式一：Lightroom 官方「预设」面板（推荐）

1. 在 Develop 模块调好一张照片
2. 左侧「预设」面板 → 点右上角 `+` → **创建预设**
3. 只勾选你想固化的项目（**别全选**——见下面的坑）
4. 预设会存到：
   ```
   %APPDATA%\Adobe\CameraRaw\Settings\
   ```
5. 把生成的 `.xmp` 复制到本目录

### 方式二：用 MCP 工具

```
create_develop_preset(photo_id, preset_name, settings=[...])
export_develop_preset(preset_name=..., destination_dir="presets/")
```

> ⚠️ **注意区别**：`create_develop_preset` 创建的是**插件管理的检查点**，
> 它**不会出现在 Lightroom 的「预设」面板里**。要给别人用的预设，走方式一，
> 或者用 `export_develop_preset` 把检查点导成文件。

## ⚠️ 存预设时最容易犯的错

**不要把「裁切」「白平衡」存进预设。**

| 项目 | 要不要存 | 原因 |
|---|---|---|
| 曝光 / 对比 / 高光 / 阴影 | ✅ 存 | 这是风格的一部分 |
| 色调曲线（含分通道） | ✅ 存 | **风格的核心** |
| HSL / 颜色分级 | ✅ 存 | 风格 |
| 暗角 / 颗粒 / 降噪 | ✅ 存 | 风格 |
| **白平衡（色温/色调）** | ❌ **不要** | 每张照片的现场光都不同。存了会把错误色温套到所有照片上 |
| **裁切 / 旋转 / 透视** | ❌ **不要** | 每张构图都不同 |
| **局部调整蒙版** | ❌ **不要** | 蒙版位置是照片专属的 |
| **修复画笔 / 污点去除** | ❌ **不要** | 同上 |

> 💡 存之前问自己一句：**「这条设置换一张照片还成立吗？」**
> 不成立的就别勾。

## 命名约定

```
presets/
├── 001-冷青电影.xmp
├── 002-黄昏暖调.xmp
└── 003-夜街霓虹.xmp
```

- 用**序号前缀**保证在 Lightroom 里排序稳定
- 名字用**中文没关系**，Lightroom 和 git 都支持
- **别用「final」「v2」「新的」这种名字**——三个月后你不知道哪个是哪个

---

## 导入给别人用

对方把这批 `.xmp` 复制到 `%APPDATA%\Adobe\CameraRaw\Settings\`，重启 Lightroom，预设面板里就有。

**或者**：直接用 MCP 的 `apply_develop_preset` 按名字套用，不用手动导入。
